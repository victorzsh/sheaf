A canvas for the pile of PDFs you actually have.

Sheaf lays every document out as a strip of real, readable pages on one plane you pan and zoom. It copies them into a library of its own, so closing the app — or deleting the originals — costs you nothing.

Download for macOS v0.1.1 · free · universal · notarized · macOS 14+

Three views, one library

The canvas is the point of the app and it is what opens. But a canvas is the wrong tool for renaming eight files in a row, so the same library is also a list and a grid. They are views, not copies: fold a folder in one and it is folded in all three.

What it actually does

Five things, stated plainly.

It keeps its own copy
Importing a PDF copies it into a .sheaf package, content-addressed, so importing the same file twice costs nothing and moving the original to the bin costs nothing either. There is one library, opened at launch and saved on its own. No save dialog, ever.
It syncs, and it merges
The library lives in Sheaf's own iCloud container, so every Mac on your Apple Account opens the same one. Two Macs edited offline merge rather than overwrite: both sides' imports survive, the newer edit wins when they collide, and a deletion beats any copy older than it.
660 pages is one row
Only the rows near the viewport are ever built, so the canvas opens at the same speed whether the library holds ten documents or a thousand. The dictionary in the screenshot above is a single 660-page document.
Search reaches every page
⌘F searches the whole library, not the document you happen to have open, and scans are read with Vision so a photographed page is findable too.
Exports are just PDFs
Export the library as one PDF, or as a zip holding one PDF per document. Nothing proprietary, nothing stapled on: files that any reader opens normally.
